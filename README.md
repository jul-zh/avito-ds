# Обнаружение ботов по поведенческим событиям

Решение задачи бинарной классификации пользовательских cookie на основе истории событий на платформе Авито.

**Цель:** определить вероятность автоматизированной активности по поведению пользователя в заданном временном окне.

Основная метрика соревнования — **Precision при Recall ≥ 70%**.

## Результаты

Итоговые оценки на тестовой выборке соревнования:

| Модель | Precision@Recall ≥ 70% |
|---|---:|
| Global CatBoost Ensemble | **0.79** |
| Hybrid Ensemble | **0.82** |

Основным решением выбран гибридный ансамбль.

## Подход

История событий каждого cookie преобразуется в набор из **163 поведенческих признаков**:

- интенсивность и разнообразие активности;
- временные интервалы и характеристики сессий;
- поисковое и навигационное поведение;
- повторяемость действий;
- статистики координат указателя.

Для обучения используется CatBoost и ансамблирование моделей с фиксированными случайными состояниями.

**Особенность решения — гибридная архитектура:** предсказания общей модели, обученной на всех cookie, объединяются с предсказаниями специализированных моделей для пользователей с доступными координатами указателя и без них.

## Валидация

Применяется хронологическая валидация на трёх последовательных временных периодах. Это позволяет оценивать устойчивость модели к временному сдвигу и соответствует расположению тестовых данных после обучающих.

Все признаки рассчитываются исключительно по событиям внутри индивидуального окна наблюдения:

`window_start_ts <= event_ts < window_end_ts`

## Воспроизводимость

Ноутбук содержит:
- исследовательский анализ данных и визуализации;
- baseline и сравнение групп признаков;
- эксперименты с гиперпараметрами;
- обоснование гибридной архитектуры;
- результаты временной валидации;
- финальное обучение и генерацию `submission.csv`.

Используемые библиотеки: Python, pandas, NumPy, scikit-learn, CatBoost и Matplotlib. Случайные состояния моделей зафиксированы.

Решение не использует внешние API, большие языковые модели или информацию из событий за пределами разрешённого окна наблюдения.
